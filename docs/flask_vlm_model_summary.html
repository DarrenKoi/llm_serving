Flask VLM

PPT 슬라이드도 읽고, PDF 이미지도 보고, GUI 자동화까지

지금 쓰는 Flask VLM 환경에서 바로 붙여 볼 수 있는 5개 모델을 간단히 정리했다. 핵심은 어떤 모델이 화면 읽기, OCR, 클릭 포인트 찾기, GUI 해석에 더 잘 맞는지다.

PPT Slides PDF Images GUI Automation

지금 보면 되는 5개 모델

GUI 주력

UI-Venus-1.5-8B

화면 구조 파악, 클릭 후보 찾기, GUI grounding 에 가장 균형이 좋다.
무엇을 잘하나
  • 스크린샷에서 중요한 버튼, 패널, 입력 영역 같은 UI 요소를 읽기 좋다.
  • 화면 분석과 다음 navigation 판단을 함께 보기 좋다.
  • PPT 화면, 앱 화면, 업무용 GUI 같이 구조가 있는 이미지를 해석할 때 무난하다.
강점 포인트
  • 5개 중 가장 범용적인 GUI 기본 카드다.
  • 화면 분석용 첫 선택지로 두기 편하다.
  • 복잡한 자동화 전에 먼저 화면을 읽어 주는 역할로 잘 맞는다.
현장형 GUI

MAI-UI-8B

실제 사용자 상호작용과 모바일 중심 흐름을 더 강하게 보는 쪽이다.
무엇을 잘하나
  • 사용자가 다음에 무엇을 누를지, 어떤 행동 흐름이 자연스러운지 해석하기 좋다.
  • 모바일 느낌의 화면이나 실제 사용 시나리오에 잘 맞는다.
  • 도구 호출이나 협업형 에이전트 흐름과 연결해 생각하기 좋다.
강점 포인트
  • 실사용 문맥, 운영형 시나리오 해석이 선명하다.
  • 단순히 화면을 읽는 것보다 행동 의도를 설명할 때 강점이 있다.
추론형 에이전트

UI-TARS-1.5-7B

단순 클릭 탐지보다 reasoning-heavy computer use 성향이 더 강하다.
무엇을 잘하나
  • 브라우저 사용, 앱 사용, 범용 computer-use 시나리오를 넓게 다룬다.
  • 다음 행동을 왜 선택해야 하는지 reasoning 흐름을 붙여 보기 좋다.
  • 복잡한 GUI 자동화 전 단계 실험에 어울린다.
강점 포인트
  • 5개 중 에이전트 성향과 범용성이 가장 넓다.
  • 단계적 판단이 필요한 화면에서 비교 실험용으로 좋다.
기본 OCR

PaddleOCR-VL-1.5

텍스트 많은 화면, PDF 이미지, 표지 화면 같은 OCR 작업의 기본 선택지다.
무엇을 잘하나
  • 이미지 안의 텍스트를 읽고 정리하는 역할에 잘 맞는다.
  • PDF를 이미지로 만든 뒤 내용 추출할 때 쓰기 좋다.
  • 문서형 화면, 텍스트 중심 슬라이드 캡처에도 잘 맞는다.
강점 포인트
  • 현재 운영 구조에서 가장 실무적인 OCR 기본 카드다.
  • 텍스트 중심 이미지 처리에서 단순하고 안정적으로 쓰기 좋다.
보조 OCR

GOT-OCR-2.0-hf

OCR 전용 fallback 이나 별도 OCR 검증용으로 보면 이해가 쉽다.
무엇을 잘하나
  • 이미지 텍스트 추출을 별도 경로로 검증할 때 좋다.
  • 기본 OCR 결과와 비교해 보는 보조 카드로 쓸 수 있다.
  • PDF 이미지, 잘린 캡처, OCR 정확도 비교 실험에 어울린다.
강점 포인트
  • OCR 전용 실험용 카드로 분리하기 쉽다.
  • 기본 OCR 외에 한 번 더 확인하는 fallback 성격으로 이해하면 편하다.

UI-Venus 이렇게 쓰면 된다

가장 단순한 연결 방식 requests.post image + dict payload

설명은 길게 필요 없다. 이미지를 base64 로 바꾸고, JSON dict 로 POST 하면 된다. 화면 읽기, PPT 슬라이드 캡처, PDF 이미지, GUI 분석 모두 같은 형식으로 붙인다.

POST URL: http://vlm-host.internal/api/vlm_serve/ui-venus/v1/chat/completions 
import base64
from pathlib import Path

import requests

img_b64 = base64.b64encode(
    Path("/ABS/PATH/TO/sample.webp").read_bytes()
).decode("utf-8")

payload = {
    "model": "ui-venus-1.5-8b",
    "messages": [
        {"role": "system", "content": "Respond only with JSON."},
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": "Analyze this image and return the important UI items in JSON.",
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": f"data:image/webp;base64,{img_b64}"
                    },
                },
            ],
        },
    ],
    "temperature": 0.0,
    "max_tokens": 1024,
}

r = requests.post(
    "http://vlm-host.internal/api/vlm_serve/ui-venus/v1/chat/completions",
    json=payload,
    timeout=120,
)
r.raise_for_status()

result = r.json()
print(result["choices"][0]["message"]["content"])
다른 모델도 방식은 같다. 바꿀 것은 URL 과 model 값뿐이다.
